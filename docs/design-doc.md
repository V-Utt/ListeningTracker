Problem Statement: 
People often listen to more songs and albums than they can count, leading to forgetting songs and albums they've liked in the past and would like to revisit later. 

Idea:
An application that functions as a tracker of listening progress. Based on user entries, this application displays their listening history and progress and their personal ratings of it. 

Chunked Build Plan (MVP):
1. Create Swing GUI for Listening History page (minimum functionality) 
2. Create "Create new Listening list" button
3. Edit Listening List Button
4. Create "Add music" button
5. Sort button for album/single/EP
6. Add personal rating (1 -10) 
7. Display compact version of Listening list
